# Filip Łodyga — personal page

Statyczna strona personalna w stylu premium consulting / finance.

## Pliki
- `index.html` — struktura strony
- `styles.css` — layout, responsywność, animacje, paleta kolorów
- `script.js` — animacje przy scrollu i menu mobilne
- `assets/favicon.ico` — aktualne logo / favicon
- `assets/hero-dashboard.svg` — grafika hero / mockup dashboardu
- `assets/og-image.svg` — grafika do podglądu social media

## Do podmiany przed publikacją
1. Przycisk „Pobierz CV” — obecnie prowadzi do kontaktu; można podpiąć plik PDF CV.
2. Case studies — obecnie są zanonimizowane i przykładowe.
3. Zdjęcie — nie dodałem, bo nie było dostarczone. Strona działa bez zdjęcia, oparta o grafikę dashboardu.
